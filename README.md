# tree-sitter-cartan

The tree-sitter grammar for cartan documents (`.cart`). Cartan is a
first-order, total, declarative dataflow language for technical
computing.

**This repository is generated.** The grammar's source of truth is a
Rust value in the language's repository; `cartan grammar` prints
`grammar.js` from it, `tree-sitter generate` produces `src/`, and this
mirror is refreshed as part of each release, the way a wheel is built
per release. Editing it here would be overwritten, and a grammar
question is a question about the language.

The scope is `source.cartan`, the file type is `cart`, and a markdown
fence holding cartan opens with the tag `cart`.
